# 01 — Requirements (PRD)

**Due: Week 5, 2 Aug 2026 (10% of final mark)**

The Project Requirements Documentation, agreed with the supervisor, should
specify:

- Purpose and overall description
- Research summary (see `../02-research/`)
- Functional requirements
- Non-functional requirements
- Base requirements (minimum), "nice to have" additional requirements, and
  stretch goals
- System features and business model (if applicable)
- Development tools and methodology selected
- Relevant regulations (e.g. PDPA for handling children's/user data)
- Work Breakdown Structure (or link to `../07-project-management/`)
- Roles & responsibilities
- Project schedule / Gantt chart

File naming: `FYP-26-S3-18-PRD.docx` (or `.pdf` for the submitted version).
