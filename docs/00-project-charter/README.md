## Project Brief (as issued)

> This project involves designing a user-friendly platform [chatbot app] to
> recommend books and videos for kids. The chatbot will be able to respond
> to queries about age-appropriate books and videos for children, as well
> as provide additional information about the content.
>
> Key features: NLP capabilities to understand and respond to user
> queries; a database of books/videos with content, age-appropriateness,
> and other relevant features; a recommendation engine leveraging models +
> database for personalized recommendations; a user-friendly, easy to
> navigate interface.
