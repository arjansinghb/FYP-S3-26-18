# 02 — Research

Market research and literature review feeding into the PRD. For this
project, useful comparison points include:

- Existing kids' book/video recommendation apps and reading platforms
  (e.g. Epic!, Vooks, YouTube Kids, Common Sense Media, Goodreads Kids).
- NLP/chatbot approaches for query understanding (intent classification,
  entity extraction, dialogue management) and what libraries/frameworks
  are viable (e.g. Rasa, spaCy, LangChain + an LLM API, Dialogflow).
- Age-appropriateness / content-rating data sources or APIs (e.g. Google
  Books API, Common Sense Media, YouTube Data API).
- Recommendation techniques (content-based, collaborative filtering,
  hybrid) suitable for a cold-start, kid-safe context.

Drop competitor comparison tables, survey results, and literature review
write-ups here. Keep raw survey data/spreadsheets alongside the writeup.
